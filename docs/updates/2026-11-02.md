# 酒馆里多了一位旅伴，书架也添了新故事

这次不是凌巽一个人的介绍页啦。来自雷族的震烁也来到了酒馆，首页便跟着重新整理了一遍：不同角色有各自的资料，不同故事也终于有了能慢慢续写的位置。

## 一、先认识一下这里的角色

- “冒险者登记簿”改为“角色介绍”，首页文案也调整为角色设定、故事与生活记录，凌巽仍然是站主和主设定。
- 角色照片与资料分列在斜线两侧，用圆形头像和箭头选择角色。物种、职业和其他资料并排展示，不用再到处找。
- 切换时，文字和照片一起沿斜向滑动；重新处理图片加载与裁切，减少整张照片突然闪出来的情况。
- 固定桌面资料区的位置，手机上则让内容高度平滑变化，不再因为介绍长短不同就突然跳一下。
- 给凌巽补充了职业、生活和带徒日常的介绍。震烁暂时没有角色图，先留一个位置，之后再补。

## 二、把角色故事摊成一本书

故事区保留书名、简介、阅读入口和篇章摘目，不再放一张重复的大图。

- 两部故事共用固定大小的书框，切换时只让书内内容按方向平移，不会一会儿高、一会儿矮。
- 可以点角色头像，也可以用书两侧的箭头切换；手机把箭头收在头像旁边，不额外空出一整行。
- 清掉书下重复的页码和“下一部”提示，阅读与完整目录入口留在书页里面。
- 明暗主题、短屏排版和栏目入场一起调整，箭头也补上悬停高亮与轻微抬升。

## 三、故事可以一章一章更新了

以后不用把整篇故事一次性塞进一条动态，也不用每更新一章就让动态列表多出一条记录。

- 一部故事在动态列表里保留一个入口，章节收在对应故事下面。
- 每章可以填写章节标识、标题、顺序和正文，分别保存草稿或公开发布。
- 公开章节有自己的阅读链接，目录自动汇总；阅读页顶部和文末都能查看目录、切换上一章或下一章。
- 原有《凌巽传》全文和章节跳转继续保留，评论仍归在对应故事下面，不会按章节拆散。
- 震烁的故事从序章开始，后面的旅途会继续更新。

## 四、后台也把位置分清楚了

- “动态管理”和“故事管理”分开，普通手记、故事简介与章节不用挤在同一个列表里找。
- 角色主展示图和圆形选择头像可以分别设置。头像支持上传、拖动取景，以及水平、垂直和缩放调整，角色介绍与故事集共用这张小头像。
- 故事简介可以在后台单独修改，角色资料和详细介绍也保留编辑入口。
- 补上前台位置提示，让“这一栏到底改哪里”更容易对应。

## 五、上传开始了，会告诉你一声

之前选完图片后没什么反应，确实很容易以为没传上去，然后又点了几次。这次把反馈统一补上了。

- 图片或文件开始上传后立即提示，上传和处理期间持续显示状态，不会闪一下就消失。
- 暂时锁住相关选择和提交控件，同一个文件还在上传时，重复请求会合并，减少传出好几份的情况。
- 成功、失败都有对应提示，结束后恢复操作；需要保存表单的地方，仍然按原来的保存步骤生效。
- 画廊、角色图片、头像、动态配图、故事封面和其他文件上传共用这套反馈，手机与明暗主题也一起适配。

原有照片、手记、留言、友链、行程、联系方式和小游戏都保留着。开启系统“减少动态效果”时，网站也会收敛位移动画。
